# Garment Material Stock Management System

A web-based stock management system developed for managing garment materials efficiently across multiple storage locations.

## User Roles

- Administrator
- Store Manager
- Production Officer

## Main Features

### Administrator
- Login
- Dashboard
- User Management
- Material Management
- Category Management
- Storage Location Management
- View Current Stock
- Manage Stock Adjustment Requests
- Transaction History
- Reports
- AI Assistant

### Store Manager
- Login
- Dashboard
- View Current Stock
- Manage Materials
- Manage Categories
- Stock Transactions
- Manage Material Requests
- Stock Transfer
- Request Stock Adjustment
- Transaction History
- Reports
- AI Assistant

### Production Officer
- Login
- Dashboard
- View Current Stock
- Request Materials
- AI Assistant

## Technologies Used

### Frontend
- React.js
- Tailwind CSS
- Poppins Font
- Google Material Icons

### Backend
- Node.js
- Express.js

### Database
- MySQL

### Additional Technologies
- JWT Authentication
- Nodemailer
- Chart.js
- OpenRouter API
